# TPA sample 1 Instructions

## Description
This folder contains copilot instructions for vibe coding new features, using the think, plan, act methodology combined with coding best practices. It is meant as a sample to continue from, to adapt to the needs or technology used in your specific project. The primary reference is `copilot-instructions.md`, which defines the TPA workflow to be used and general best coding practices to adhere to. It also refers to a specific set of instructions when writing code for the backend / frontend.

## Features
- Instructions that follow TPA approach, create a plan, update the docs. Refer to backend / frontend specific instruction when coding in those particular areas.
- Instructions that follow coding best practices
- It asks to construct a plan, be critical of the implementation, not to take assumptions, etc. Only when a good plan in the /plan folder has been set up.
- Approving a plan goes hand in hand with creating documentation in the /docs folder.
- Frontend (& backend) specific frameworks can be edited to suit the technology used in your project.
